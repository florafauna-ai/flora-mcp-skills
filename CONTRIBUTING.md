# Contributing

This repository is a public distribution mirror. FLORA maintains skills in
`packages/skills-ts/skills/` in the `florafauna-ai/flora-frontend` monorepo.

FLORA maintainers: edit skills in the monorepo, regenerate the TypeScript registry,
and submit a monorepo pull request. Maintainers publish reviewed main-branch changes here manually with the mirror script.
Direct edits to this mirror's skills are overwritten by publication.

Community contributors: open an issue here with your proposed workflow or correction.
A maintainer will incorporate accepted changes in the monorepo.
